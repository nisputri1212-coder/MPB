# Business Research Methods (MPB) Learning Portal

Welcome to the **Business Research Methods (MPB) Learning Portal**. This project is an interactive Single-Page Application (SPA) designed to help students understand the stages of business research, particularly focusing on post-midterm materials (Weeks 8 to 14).

## 🎯 Learning Objectives

This portal was created so that students don't just read theory, but can interact directly with simulated research data. Students can see how raw questionnaire responses are transformed into variable scores ready to be analyzed using statistical software (such as SPSS or Jamovi).

## ✨ Key Features

1. **Interactive Syllabus:** Course guides, assignments, and reading references from Week 8 to Week 14.

2. **Questionnaire Simulator (Data Transformation):** Students can fill out a simulated questionnaire and see in real-time how the system calculates scores for variables like Trust, Risk, and Intention, including the application of reverse coding.

3. **Dataset Exploration:** A preview of the synthetic dataset (`01_Dataset_Latihan_MPB_P8-P12.xlsx`) in an easy-to-read table format.

4. **Interactive Data Visualization:** A feature to simulate bivariate analysis. Students can experiment with Scatter Plots (for correlation) and Bar Charts (for comparing means/T-Tests) along with automated interpretations.

5. **Concept Library:** Summaries of theories and concepts from main literature (Creswell, Sekaran, Zikmund) tailored to the weekly materials.

## 🚀 How to Run Locally

Because this app is fully frontend-based and does not require a database or backend server, running it is very easy:

1. Clone or download this repository to your computer.

2. Open the downloaded folder.

3. Double-click the `index.html` file to open it in a browser (Chrome, Firefox, Safari, Edge, etc.).
